# 白银三频共振面板

本地 web 面板：监控白银期货三个周期（15分 / 3分 / 30秒），三频共振时中央大灯亮起并响铃，提醒你抬头细看是否建仓。

## 这是什么 / 解决什么问题

**需求背景：** 做白银期货日内超短线时，需要同时盯多个周期——大周期定方向、中周期看位置、小周期抓入场时机。人工来回切周期盯盘容易疲劳、错过时机，也容易在情绪驱动下追高杀跌。

**用户诉求：** 要一个「不用一直盯盘」的提醒器——当三个周期的技术方向真正对齐（共振）时，用**大灯 + 声音**主动提醒我抬头看一眼，判断是否建仓；没对齐时保持安静，避免我频繁手动切周期、避免冲动开单。

**它做什么：** 只做**技术方向对齐的过滤与提醒**，把「值得看一眼」的时刻筛出来。

**它不做什么：** 不自动下单、不替你做进场决策、不保证盈利。亮灯只是「可以看一眼」，不是「立刻进场」。

## 三频共振逻辑（按交易纪律设计）

| 周期 | 角色 | 判定 |
|------|------|------|
| **15分** | 主战场·定方向 | 均线多头/空头排列 + 慢均线有斜率 → long / short / none |
| **3分** | 过滤位置 | 方向须同向 15 分，且现价未过度偏离慢均线（避免在压力/支撑极端位追单） |
| **30秒** | 触发入场 | 短均线拐头 + 现价站上/跌破短均线（近似企稳信号） |

三者同向且各司其职 → **共振**（大灯：做多=红 / 做空=绿，涨红跌绿）。任一环节不满足 → 观望（灰灯）。

> ⚠️ **亮灯 ≠ 可进场。** 面板只判断技术方向对齐，是过滤器不是下单扳机。盈亏比、支撑/压力位、CCL 持仓方向仍须你手动确认。

## 分发使用（给别人用，免安装）

**打包 exe：** 双击 `build.bat` → 生成 `dist\SilverResonance.exe`。

**分发：** 把 `dist\SilverResonance.exe` 单个文件拷到任意 Windows 电脑，双击即可运行，目标电脑**不用装 Python**。

**首次运行：** 会自动开浏览器弹出配置页，让填**自己的天勤账号 + 密码**（免费注册：[shinnytech.com/tqsdk](https://www.shinnytech.com/tqsdk/)）+ 选合约。账号密码与合约存在 exe 同目录 `user_config.json`（密码不会回传前端）。
- 同一天勤账号不能多台电脑同时登录，每台机器用各自账号。
- 换月时在配置页改合约代码（如 `SHFE.ag2609`）即可。

**启动进度条：** 每次启动显示进度（起服务→连天勤→校验合约→拉K线→就绪），就绪后自动进面板。连接失败会显示错误 + 重试按钮。

**若卡在「正在拉取三周期K线」：** 行情线程有 30 秒看门狗，超时会自动报错并说明可能原因，不会永久卡住。常见原因：
1. 合约非当前主力 / 已换月（去配置页改成当前主力合约）。
2. 同一天勤账号在别处已登录（同账号不能多台设备同时在线）。
3. 当前为非交易时段且无历史缓存。

## 快速开始（开发/源码运行）

### 1. 装依赖（建议用虚拟环境）
```powershell
cd d:\SilverResonance
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. 先用模拟模式看界面（无需网络/账号）
`config.py` 里默认 `MOCK_MODE = False`（连真实行情）。想先离线看界面，把它改成 `True` 再跑：
```powershell
python app.py
```
浏览器打开 http://127.0.0.1:8848 ，能看到大灯随模拟数据在做多/做空/观望之间切换。

### 3. 接真实行情
1. 到 [天勤量化官网](https://www.shinnytech.com/tqsdk/) 注册免费账号（快期账号）。
2. 编辑 `config.py`：
   - 填 `TQ_USER` / `TQ_PASSWORD`
   - 把 `MOCK_MODE` 改为 `False`
   - 换月时改 `SYMBOL`（如 `SHFE.ag2609`）
3. 重新 `python app.py`。

## 可调参数（都在 config.py）
- `MA_FAST` / `MA_SLOW`：均线周期
- `TREND_SLOPE_MIN`：趋势斜率门槛（太敏感就调大）
- `OVEREXTENSION_PCT`：过度延伸保护，越小越严格（越不容易在追高时亮灯）
- `POLL_INTERVAL_MS`：前端刷新频率

## 文件结构
```
config.py        参数配置（合约/周期/均线/阈值/账号/模式）
user_settings.py 用户配置读写（user_config.json 的加载/保存）
resonance.py     三频共振纯函数（可单独测试）
app.py           TQSDK 数据线程 + Flask 后端
templates/
  index.html     面板界面（大灯+三腿+声音提醒）
  setup.html     首次运行配置页（填天勤账号/密码/合约）
build.bat        一键打包 exe（自动定位 Python + 装依赖 + PyInstaller）
build.spec       PyInstaller 打包配置
```
