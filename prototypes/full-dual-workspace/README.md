# 完整工作台双品种本地样板

这次样板直接使用当前工作台的完整模板、图表、绘图工具、计划、风控评审、图层、历史版本、案例和协作接口。在此基础上增加双品种上下显示，原项目文件保持原样。

## 打开与停止

- 双击此目录的 `start-preview.bat`，然后打开 `http://127.0.0.1:8865/`。
- 也可在项目根目录运行 `python -X utf8 -B prototypes/full-dual-workspace/server.py`。
- 服务只在本机监听；按启动终端中的 `Ctrl+C` 停止。不需要账号密码，不连接实盘账户。
- 如果端口被其他程序占用，可以加 `--port 8866`。不同端口的浏览器偏好互相独立。

## 功能与数据

- 默认一个品种；从列表拖入其他品种，下方出现虚线放置引导。双窗口时拖到目标窗口替换；已有品种只切换当前操作对象。
- 品种栏每次进入先显示“全部”；默认、喜爱初始为空，空组没有重复的“查看全部”按钮。用户后续添加的成员和拖拽排序会保留。本次升级只重置旧样板分组一次，不会反复清空。
- 两窗口时显示小 `×`，关闭后剩余窗口铺满。关闭、替换不会删除对应品种的计划。
- 顶栏标明“正在编辑”的品种；点击另一窗口切换操作对象，共用一套工具和侧栏。未提交的文本会先提示完成或取消，避免切换时丢失。
- 两个品种窗口始终保留；菜单、案例和评审弹层限制在所属窗口内。选中切换不再改变指标栏、底栏高度，计划栏没有纵向滚动条；右侧栏默认 204px，仍可手动扩宽。
- 两窗各自保存多周期布局、活动周期和单图放大状态。单击空白不关闭跟随，实际平移或缩放后可点“回到最新”。保存计划时行情仍可更新；启动请求有超时与重试。
- 品种标题栏的“工作区全屏”图标控制整个页面工作区，两个图标状态同步。已打开的两个品种窗口与绘图工具保持显示，周期排列不变；左侧品种大纲、右侧计划/图层默认收起。两侧边缘各有一个展开/收起按钮，预留 18px 边条，不覆盖图表价格轴。再次进入全屏仍默认收起两栏。
- 全屏内展开左栏后可切换、拖入品种，也可点任一品种的“×”关闭该窗。关闭后剩余窗口铺满，全屏继续；重新拖入第二个品种后恢复上下双窗，全屏继续。侧栏开合由整个工作区统一控制，切换窗口不会重置，两边行情更新和共享计划同步保持运行。
- 全屏不切换当前编辑品种，不重置单图放大/图表定位/跟随。全屏侧栏开合是临时状态，退出后恢复原右侧栏开关和宽度、显示左栏；普通模式的偏好不被覆盖。若右侧存在未完成表单或输入法组合，会保留视图并提示先完成或取消，避免隐藏输入导致失焦保存。全屏状态只属于当前页面，刷新回到普通布局，不写入共享计划。Esc 优先处理浮层及当前编辑，再退出全屏。
- 切换/关闭前统一检查受影响窗的未完成编辑；等待保存后再次检查，避免慢保存期间新建的草稿被关闭。关闭非活动窗不提交当前窗草稿。未完成文字需显式添加或取消。
- 完整工作台功能由原组件和原 API 提供，案例仍使用项目当前维护的案例数据，规则文件按原路径只读加载。
- 所有 K 线、成交量、持仓量与报价都是**模拟数据**。三周期源于同一模拟序列，供交互验收；不代表真实行情或交易日历，评审不会形成实盘开仓许可。
- 页面每 5 秒检查数据；当前模拟器在简化日盘内按 3 分钟推进，同一根 K 线内不会逐笔跳价。模拟收盘后及夜间保留最后价，此时“检查时间”仍会更新，不表示刷新已暂停。启动接口每次最多等待 12 秒，暂时失败会有限重试。
- 计划、历史、身份、个人风控只写入本目录 `data/workspace.json`；协作指针为样板内存状态。可用两个本地浏览器窗口检验样板内的同步。
- 样板采用独立会话 Cookie，不会覆盖同一电脑正式工作台的会话。浏览器草稿和布局按样板端口隔离。
- 未导入 `app.py`，未启动行情线程，未读取行情账号，未代理正式服务，未写入项目原 `state/` 或修改正式共享计划。
- 服务只绑定 `127.0.0.1`，朋友通过原地址看到的页面不会变化。本地样板里的修改不会同步到原共享工作区。

## 修改与回退

前端文件每次请求重新读取，修改后刷新页面即可；修改服务代码后重启这个样板服务。样板会核对原页面适配位置，如果原工作台发生不兼容更新，会停止提供适配脚本而不是悄悄遗漏功能。

回退时关闭样板页并停止此服务即可，原工作台继续使用。若不再保留本次样板，先备份本目录 `data/` 中需要的计划，再只移除此目录；无需 Git 重置，也不影响先前品种分类、碳酸锂等工作。

模拟生成器与窗口模型只读复用上一版 `prototypes/dual-symbol-workspace` 的文件，因此试用期间请保留该目录。其服务无需启动。

## 本地验证

在项目根目录运行 `python -X utf8 -B -m unittest discover -s prototypes/full-dual-workspace -p "test_*.py"`。

检查完整模板与静态资源、独立会话、计划保存/历史/评审、协作事件、模拟行情字段及路径隔离。测试还会通过已安装的 Node.js，将实际服务响应交给原行情缓存组件验证，避免页面因数据格式不兼容而停用工具。不会连接正式行情或正式服务。
