# 双品种本地样板

此目录是独立试用入口。现有工作台页面、线上服务和已有项目修改都保持原样。

## 打开与停止

- 双击本目录的 `start-preview.bat` 启动服务，然后在浏览器打开 `http://127.0.0.1:8864/`。
- 也可在项目目录运行：`python -X utf8 prototypes/dual-symbol-workspace/server.py`。
- 端口已被占用时，可用 `--port 8865` 指定另一个端口。端口变化会使用另一份浏览器存储。
- 在启动样板的终端按 `Ctrl+C` 即可停止。已有工作台服务不会停止。

## 试用范围

- 默认上下显示，拖入品种新增或切换窗口；多个窗口时点小 `×` 关闭，剩余窗口自动铺满。
- 一窗时拖入另一个品种，出现下方虚线预览；双窗时拖到哪一窗就替换哪一窗。拖出工作区或按 `Esc` 取消；拖入已经显示的品种只切换当前操作对象。
- 点击窗口切换编辑对象；点击左侧品种只更换当前窗口。键盘聚焦品种后按 `Shift+Enter` 也可同时打开。
- 默认和喜爱分组可以拖拽排序；也可将品种拖到分组标签。键盘聚焦品种后按 `Alt+↑/↓` 调整顺序。
- 计划栏显示当前品种，价位可输入或直接在图上标记、拖拽。关闭或替换窗口会保留该品种的计划和画线；撤销仅作用于当前品种。
- 复用项目图表与品种分类组件，品种目录通过 `symbols.PRESETS` 只读取得，包含碳酸锂。
- 全部K线均为**模拟行情**。价格、成交量、持仓量与简化日盘时段用于检验界面，不是实际行情或交易日历。三周期来自同一示意序列，收盘价保持一致。
- 计划、画线和布局仅存于这个样板页面的浏览器中，**不与朋友同步，不写入原工作区，不执行下单**。
- 样板服务只绑定 `127.0.0.1`，不会开放到局域网；没有账号、密码或实盘行情连接。

## 随时回退

1. 关闭样板网页，停止它的终端，继续使用原工作台地址即可。
2. 如果彻底放弃这次样板，仅移除 `prototypes/dual-symbol-workspace` 这个目录；无需重置 Git，也无需回退此前品种分类、碳酸锂等修改。
3. 原有 `state/`、账号配置与在线数据均未由本样板写入。浏览器中的样板记录可保留供下次继续试用。

后续迭代只改此目录，确认交互后再评估接入正式工作台。服务每次请求重读前端文件，编辑后刷新即可看到新样式；更新 Python 服务文件后需重启本样板服务。

## 本地检查

`python -m unittest discover -s prototypes/dual-symbol-workspace -p test_server.py`

`node --test prototypes/dual-symbol-workspace/test_model.cjs`

`node --test prototypes/dual-symbol-workspace/test_interaction.cjs`

检查模拟数据、品种目录、白名单路由、窗口状态和迟到数据防护。交互检查在简化 DOM 中运行完整页面程序，覆盖拖入、取消、关闭和计划隔离，不启动浏览器或实际行情；虚线位置和图表拖拽效果另在样板页面验收。
