# 移动端只读看盘

2026-11-12 08:37 已部署至 https://resonance.cg-x.com/workspace 。发布版本 `20261112-367d88ebb6b5`，代码提交 `7e8130d`，前端变更资源版本19。

## 使用方式

- 手机自动进入“只读看盘”。窄窗口宽度不超过 900px 时也可预览；移动设备使用“桌面网站”模式时，仍结合触摸点与主指针类型保持只读。
- 固定单列：30 分钟、3 分钟、日线，纵向滚动查看。横屏仍保持这三个周期。
- 上方选择品种和共享计划；先展示三周期图表，再在图表下方展开“当前计划”，查看入场、止损及多行备注。
- 行情和当前计划持续更新，显示同一计划内伙伴的鼠标、编辑目标、拖动预览和最终修改。
- 在线名单可主动跟随伙伴视角；图表复位、缩放和全显仅改变自己的观看范围。
- 顶栏吸顶，连接通知占固定高度，不挤压图表。

## 只读边界

前端不提供绘图、拖点、双击修改、删除、属性编辑、新建/归档计划或个人设置编辑。图表和计划变更函数也会拒绝这些操作，旧桌面草稿不会在手机端自动重放。

后端按请求判断移动设备或 `X-Workspace-View-Only: 1`，拒绝持久修改请求。允许查询、事件流和在线心跳；只读心跳会清除编辑对象和拖动预览。只读状态不写入用户身份，不会影响同一用户的电脑端。这是设备交互模式，不代替身份权限体系。

桌面缩到手机尺寸时，未提交草稿保留在原文档键下；重新回到桌面才进入原草稿恢复流程。已经由服务器满足的草稿会清理，避免以后覆盖伙伴的新修改。手机、桌面分别保存观看范围，不改变原桌面布局。
