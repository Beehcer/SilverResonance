# 绘图不透明度

2026-11-11，代码提交 `48b09b4`。

## 使用方式

- 顶部“不透明度”设置新绘图默认值，0%–100%，自动记住此浏览器的选择。
- 选中已有元素，在“图层”属性中拖动“不透明度”滑杆或输入百分比，立即发送协作修改，无需应用按钮。
- “计划模式”中的“计划线不透明度”控制入场、止损、对应价格标签及计划参考区域。
- 0%图层仍可从图层列表选中，通过独立选中框和控制点恢复或编辑；并未删除对象。

覆盖水平线、水平线段、趋势线、参考线、预期浪线、旧版路径、区域、文本。线条、填充、文字和编号整体调整，K线、均线、十字线与伙伴光标独立显示。

大周期预期线映射继续逐级乘0.4。例如日线对象设50%，在30分钟为20%，在3分钟为8%。旧对象没有该字段时按100%显示，不迁移原计划。

## 数据与协作

对象字段 `opacity`、计划字段 `plan_opacity` 为可选有限数值 `[0,1]`，保留零值。非法类型与越界值拒绝写入。支持按属性合并、撤销、重入与伙伴临时预览；修改透明度不会覆盖伙伴的名称、颜色、坐标或备注。

不透明度只改变外观，不改变区域的交易含义；危险区即使完全透明，原有阻挡条件仍然有效。仅修改透明度不会重置交易计划激活状态。
